# Training Reports — Doctor / Hacker / Rider

Relatórios gerados automaticamente 2x/dia pelo sistema de auto-training.

## Formato
`YYYY-MM-DD_HHh.md` — ex: `2026-05-29_05h.md`

## Estrutura de cada relatório
- Data e hora
- Fontes pesquisadas (GitHub repos, arXiv, HuggingFace)
- Actualizações encontradas por agente
- Diffs propostos (a aprovar pelo utilizador)
- Cross-training insights
